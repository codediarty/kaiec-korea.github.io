 KAIEC AI윤리전문가 응시 접수 → 구글 스프레드시트 자동 수집
 설치 안내 (약 3분 소요)
═══════════════════════════════════════════════════════════════

[1] 구글 드라이브에서 새 스프레드시트를 만듭니다.
    (예: 이름 "AI윤리전문가 1기 접수명단")

[2] 상단 메뉴 [확장 프로그램] → [Apps Script] 를 엽니다.

[3] 편집기에 있는 기존 코드를 전부 지우고, 아래 코드를 통째로
    붙여넣은 뒤 저장(디스크 아이콘)합니다.

──────────────── 여기부터 복사 ────────────────

function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getSheetByName('접수') || ss.insertSheet('접수');
  if (sh.getLastRow() === 0) {
    sh.appendRow(['접수일시', '응시 과정', '성명', '생년월일',
                  '휴대전화', '이메일', '소속', '직업/활동 분야']);
    sh.setFrozenRows(1);
  }
  var d = {};
  try { d = JSON.parse(e.postData.contents); } catch (err) { d = e.parameter || {}; }
  sh.appendRow([new Date(), d.course || '', d.name || '', d.birth || '',
                d.phone || '', d.email || '', d.org || '', d.job || '']);

  // 접수될 때마다 협회 메일로 알림을 보냅니다. 원치 않으면 아래 3줄을 지우세요.
  MailApp.sendEmail('kaiec.korea@gmail.com',
    '[AI윤리전문가 1기 응시] ' + (d.name || '') + ' · ' + (d.course || ''),
    '새 응시 접수가 등록되었습니다.\n\n' +
    '응시 과정 : ' + (d.course || '') + '\n성명 : ' + (d.name || '') +
    '\n생년월일 : ' + (d.birth || '') + '\n휴대전화 : ' + (d.phone || '') +
    '\n이메일 : ' + (d.email || '') + '\n소속 : ' + (d.org || '') +
    '\n직업/활동 분야 : ' + (d.job || '') +
    '\n\n스프레드시트에서 전체 명단을 확인하세요.');

  return ContentService.createTextOutput('ok');
}

──────────────── 여기까지 복사 ────────────────

[4] 우측 상단 [배포] → [새 배포] 를 누르고:
    · 유형 선택(톱니바퀴) → "웹 앱"
    · 설명: 접수 수집 (아무거나)
    · 실행 계정: "나"
    · 액세스 권한: "모든 사용자"  ← 반드시 이걸로 선택
    → [배포] → 권한 승인(계정 선택 → 고급 → 이동 → 허용)

[5] 발급된 "웹 앱 URL"(https://script.google.com/macros/s/...../exec)을
    복사해서 저에게 보내주세요.
    → 제가 build.py 의 SHEET_WEBHOOK 에 넣고 재빌드해 드립니다.
    (직접 하시려면: build.py 상단 SHEET_WEBHOOK = "" 에 URL을 넣고
     python3 build.py 실행 후 재업로드)

═══════════════════════════════════════════════════════════════
 연동 후 동작
═══════════════════════════════════════════════════════════════
· 응시자가 접수 폼을 제출하면 시트 '접수' 탭에 한 줄씩 자동 추가되고,
  kaiec.korea@gmail.com 으로 접수 알림 메일이 옵니다.
· 접수자는 완료 화면에서 3초 뒤 결제 페이지로 자동 이동합니다.
· 연동 전까지는 지금처럼 접수 내용이 메일 앱을 통해 발송됩니다.

※ 참고
· 코드를 수정한 뒤에는 [배포] → [배포 관리] → 연필 아이콘 →
  버전 "새 버전" 으로 다시 배포해야 반영됩니다.
· 시트 이름/탭 이름은 자유롭게 바꿔도 됩니다('접수' 탭은 자동 생성).
